# 库存日期筛选功能开发文档

## 功能概述

为库存管理系统添加了日期筛选功能，用户可以选择任意历史日期查看该日期的实际库存数量，并支持导出功能。

## 开发时间

**开发日期**: 2024年12月28日  
**开发者**: AI助手  
**版本**: v1.0.0

## 功能特性

### 1. 历史库存查询
- **日期选择器**: 用户可以选择任意历史日期（不能超过当前日期）
- **历史数据计算**: 基于库存记录倒推计算指定日期的库存数量
- **实时筛选**: 支持关键词、状态、数量范围等筛选条件
- **视图标识**: 历史视图有明显的视觉标识

### 2. 数据导出功能
- **格式支持**: 支持CSV和Excel格式导出
- **历史数据导出**: 可导出指定日期的历史库存数据
- **文件命名**: 导出文件名包含日期信息，便于区分
- **筛选条件保持**: 导出时保持当前的筛选条件

### 3. 用户界面优化
- **日期提示**: 历史视图显示明显的日期提示横幅
- **返回按钮**: 快速返回当前库存视图
- **状态标识**: 筛选区域显示"历史视图"标签

### 3. 数据库查询逻辑

#### 历史库存计算原理
```php
// 从当前库存数量倒推到目标日期
$historicalQuantity = $currentQuantity;

// 获取目标日期之后的所有变动记录
$records = InventoryRecord::where('inventory_id', $inventoryId)
    ->where('created_at', '>', $targetDateTime)
    ->orderBy('created_at', 'desc')
    ->get();

// 反向计算
foreach ($records as $record) {
    if (in_array($record->type, ['in', 'adjust']) && $record->quantity > 0) {
        $historicalQuantity -= $record->quantity; // 入库记录需要减去
    } elseif (in_array($record->type, ['out', 'adjust']) && $record->quantity < 0) {
        $historicalQuantity -= $record->quantity; // 出库记录需要加上
    } elseif ($record->type === 'check') {
        $historicalQuantity -= $record->quantity; // 盘点记录特殊处理
    }
}
```

## 使用说明

### 1. 查看历史库存
1. 进入库存管理页面
2. 在筛选区域选择"筛选日期"
3. 选择要查看的历史日期
4. 点击"搜索"按钮
5. 系统显示该日期的库存数据

### 2. 导出历史数据
1. 选择历史日期并查看数据
2. 点击导出按钮
3. 选择CSV或Excel格式
4. 下载包含日期信息的文件

### 3. 返回当前库存
- 在历史视图中点击"返回当前库存"按钮
- 或者清除所有筛选条件

## 注意事项

### 1. 性能考虑
- 历史库存计算可能较慢，建议添加缓存机制
- 大量数据时建议分页处理
- 考虑添加后台队列处理大批量导出

### 2. 数据准确性
- 依赖库存记录的完整性和准确性
- 建议定期检查库存记录的一致性
- 对于缺失的历史记录，可能无法准确计算

### 3. 用户体验
- 历史视图有明显的视觉标识
- 提供快速返回当前库存的方式
- 导出文件名包含日期信息
